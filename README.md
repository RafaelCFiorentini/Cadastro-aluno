# Cadastro de Alunos

Projeto acadêmico desenvolvido em C# (.NET 9) para a disciplina de Algoritmos e Estruturas de Dados da PUC Minas.

## Sobre o projeto

Sistema de console para cadastro e gerenciamento de alunos, implementado com uma **lista linear manual** (array de tamanho fixo), sem uso de coleções prontas da linguagem.

## Funcionalidades

- Cadastrar aluno (código, nome e nota)
- Listar todos os alunos
- Busca sequencial por código
- Ordenação por Bubble Sort
- Busca binária iterativa
- Busca binária recursiva

## Algoritmos implementados

| Algoritmo | Complexidade |
|---|---|
| Pesquisa Sequencial | O(n) |
| Bubble Sort | O(n²) |
| Pesquisa Binária | O(log n) |
| Pesquisa Binária Recursiva | O(log n) |

## Tecnologias

- C# / .NET 9
- Console Application

## Como executar

```bash
dotnet run
```
